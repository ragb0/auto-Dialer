before run the project make sure you use the correct path of your wn file and platform-tools also you need add platoform-tools(adb) to your system so following this steps 
Right-click on "This PC" or "Computer" on the desktop or in File Explorer and select "Properties."
Click on "Advanced system settings" on the left.
Click the "Environment Variables" button.
In the "System variables" section, find and select the "Path" variable, then click "Edit."
Click "New" and add the path to your platform-tools directory (e.g., D:/platform-tools). choose your own directory 
Click "OK" to close all dialogs.
